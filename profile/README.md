## 🧰 Dependencies

Before using MHWUnlocker, ensure you have:

- A **Steam version** of **Monster Hunter: Wilds**
- The **latest release** of **CreamAPI**
- An active **internet connection** (required for SteamCMD data fetch)
- **.NET 7 Runtime** installed (if not already)

## 🚀 Activation Guide

### Step 1: Install CreamAPI

1. Download the latest release of **CreamAPI**.
2. Extract the archive to any folder (CreamAPI is fully portable).
3. Launch **CreamAPI** and follow the on-screen setup instructions to **activate DLCs** for **Monster Hunter: Wilds**.

---

## 🔧 Troubleshooting

| Problem                        | Solution                                                                 |
|--------------------------------|--------------------------------------------------------------------------|
| DLCs not showing in-game        | Run **CreamAPI as Administrator** and restart Steam.                     |
| Game crashes after launch       | Use the **Uninstall** option in CreamAPI and reinstall the unlockers.    |
| Missing DLL errors              | Reinstall **Koaloader** via CreamInstaller’s context menu.               |
| Unlocker still doesn’t work     | Re-run **CreamAPI** and refresh Steam appinfo for **Monster Hunter: Wilds**. |
